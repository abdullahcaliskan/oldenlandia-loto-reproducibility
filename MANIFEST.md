# Repository manifest

This repository contains one canonical implementation of the accepted-manuscript analysis.

| Path | Purpose |
|---|---|
| `README.md` | Study scope, methods, execution instructions, limitations, and citation |
| `CITATION.cff` | Machine-readable software citation metadata |
| `LICENSE` | MIT License |
| `requirements.txt` | Pinned Python dependencies used for the verification run |
| `run_all.sh` | Supported Linux/macOS entry point |
| `run_all_windows.bat` | Supported Windows entry point |
| `src/run_analysis.py` | Single analysis entry point |
| `src/analysis_core.py` | Data loading, fold-local preprocessing, fixed models, validation, and metrics |
| `src/reporting.py` | Dataset audit, manuscript checks, result exports, and figure generation |
| `data_input/README.md` | Official source, required filenames, and SHA-256 checksums for the three MetaboLights inputs |
| `REPRODUCIBILITY_NOTES.md` | Concise notes on the analysis design and verification |
| `figures/fig1_overview.pdf` / `.png` | Regenerated article Fig. 1 (generated by the pipeline; not versioned) |
| `figures/fig2_loto_design.pdf` / `.png` | Regenerated article Fig. 2 (generated by the pipeline; not versioned) |
| `figures/fig3_performance.pdf` / `.png` | Regenerated article Fig. 3 (generated by the pipeline; not versioned) |
| `figures/fig4_plsda_scores.pdf` / `.png` | Regenerated article Fig. 4 (generated by the pipeline; not versioned) |
| `figures/fig5_panel_ablation.pdf` / `.png` | Regenerated article Fig. 5 (generated by the pipeline; not versioned) |
| `figures/marker_measurement_presence_audit.pdf` / `.png` | Diagnostic plot; not a manuscript supplementary figure (generated; not versioned) |

The three MetaboLights input files are not versioned here. Generated `results/`, `figures/`, and `logs/` are excluded from version control; run the pipeline to regenerate them. No earlier exploratory analysis scripts are part of this canonical repository.
