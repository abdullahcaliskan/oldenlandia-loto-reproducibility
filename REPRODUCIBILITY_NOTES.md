# Reproducibility notes

- The pipeline implements the fixed-setting analysis described in the accepted manuscript.
- There are 40 estimator fits: 15 full-feature LOTO fits, 5 random-CV elastic-net fits, and 20 fixed-panel PLS-DA fits.
- LOTO uses five tissue holdouts with 48 training and 12 held-out biological samples in each fold.
- The four panel conditions reuse the same LOTO partitions.
- Preprocessing is fitted on training data only and then applied unchanged to the held-out samples.
- The script writes split-membership tables and sample-level predictions so that fold coverage can be inspected.
- The script checks the manuscript's pooled performance metrics, descriptive top-20 recurrence counts, marker detection counts and split integrity, and additionally the dataset missingness, median QC CVs, tissue-specific error patterns, within-tissue ROC-AUC, per-tissue panel accuracy and per-fold random-CV results (43 checks).
- The five-marker panel originated in an earlier exploratory analysis of the same dataset; its ablation is retrospective, not independent biomarker validation.
- The run manifest records the actual environment and input-file SHA-256 hashes. The environment used for verification differs from the versions printed in the accepted manuscript.
- The measurement-presence plot is an audit diagnostic generated by the code; it is not a supplementary figure included with the article.
